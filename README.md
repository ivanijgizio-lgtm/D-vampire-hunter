# 🦇 Кровь и Вера: Война Теней (1520)

Пошаговая стратегия на HTML5 Canvas в стиле Medieval II.  
Вы управляете кланом вампиров Дракулы против Священной Римской империи и Инквизиции.

## 🎮 Как играть
- Кликайте по соседней провинции, чтобы переместить армию Дракулы.
- Захватывайте территории, распространяйте Тьму и собирайте Кровь.
- Ночью (каждый 2-й ход) вампиры сильнее.
- Используйте кнопку «Вурдалак» (10 крови) для призыва союзных отрядов.
- Победа: захватить 80% провинций.
- Поражение: гибель Дракулы.

## 🚀 Запуск
Просто откройте `index.html` в любом современном браузере.
Никаких серверов или внешних библиотек не требуется.

## 📁 Структура проекта
- `index.html` – главная страница
- `style.css` – стили в духе 8-битного пиксель-арта
- `script.js` – вся игровая логика
- `README.md` – этот файл

## 🛠️ Технологии
- HTML5 Canvas
- Чистый JavaScript (без фреймворков)
- Пиксельная графика, нарисованная кодом

## 📜 Сеттинг
Европа 1520 года. Дракула восстал в Трансильвании. Верховный Инквизитор Вальхенсиг собирает армии Света.  
Нейтральные державы (Османы, Англия, Франция и др.) ждут своей участи.

Приятной игры!
